# Rules for every agent

Read `SPEC.md` first. It is the source of truth.

1. **Stay inside your own area.** Each agent has a defined set of files (see `.claude/agents/`). Do not edit anything outside it. If you need a change elsewhere, say so in your report and let the owner do it.
2. **Never invent test or benchmark numbers.** No made-up latencies, throughput, pass counts, or oversell counts.
3. **Only report what you actually ran.** If you did not run it, say you did not.
4. **No extra gems, features, or endpoints** beyond what `SPEC.md` describes.
5. **Always report:** (a) the commands you ran, (b) the real output, (c) what you are unsure about.
